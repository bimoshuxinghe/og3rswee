# 第三阶段：MPV 深度适配需求库

## 目标

将 MPV 从“基础播放核心”升级为接近 EXO 同级的完整播放核心，保持原播放 UI 不变，通过原 `EXO/MPV` 按钮切换播放内核。

## 需求清单

- 支持 MPV 杜比音频直通，包括 AC3、EAC3、DTS、TrueHD 等格式按设备能力透传。
- 支持音频直通总开关，并在设置页提供可见配置。
- 支持杜比相关开关设置，按设备能力控制启用或禁用。
- 支持 MPV 自动侦测 HDR，并按设备能力选择合适输出路径。
- 支持 `gpu`、`gpu-next`、`vulkan` 渲染后端配置与切换。
- 支持 MPV Vulkan 渲染链路。
- 支持 Vulkan + MediaCodec 硬解渲染链路。
- 支持 EXO 软硬解无感切换，尽量避免重建播放器。
- 支持 MPV 软硬解快速切换，尽量避免重建播放器。
- 支持 MPV 播放图片资源。
- 支持 MPV 播放 `.ts` 流。
- 支持 MPV 播放 Blu-ray ISO。
- 完整适配音轨、字幕轨、字幕偏移、音频偏移等现有播放菜单。
- 完善 MPV 错误识别、错误提示、自动恢复和必要时回退 EXO。

## 验收方向

- EXO 与 MPV 切换后，播放页 UI、遥控器操作、移动端触控操作保持一致。
- 普通 MP4、HLS、TS、图片、Blu-ray ISO 能按能力正常播放。
- HDR、杜比、音频直通在支持设备上可启用，在不支持设备上有明确降级策略。
- 软硬解切换尽量不黑屏、不重开页面、不丢进度。
- MPV 不支持的 DRM、协议或设备能力场景能自动保持或回退 EXO。

## 当前基线

- 第一阶段 MPV 基础播放接入已通过。
- 原播放 UI 保持不变，通过原 `EXO/MPV` 按钮切换播放内核。
- 已验证 `mp4` 正常播放。
- 已验证 `m3u8` 正常播放。
- 已验证高分辨率、低分辨率视频均正常播放。
- 已验证声音、画面、流畅度正常。
- 暂未验证 `.ts`、Blu-ray ISO、HDR、杜比、音频直通、音轨字幕完整菜单。
